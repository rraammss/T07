3D map not opening? Turn on graphics acceleration
Chrome
  1. Open chrome://settings/system
  2. Turn on Use graphics acceleration when available
  3. Click Relaunch
Brave
  1. Open brave://settings/system
  2. Turn on Use graphics acceleration when available
  3. Click Relaunch
  4. Still blank? Click the Brave lion icon and set Shields to Standard for this site
Edge
  1. Open edge://settings/system
  2. Turn on Use graphics acceleration when available
  3. Click Restart
Firefox
  1. Settings → General → Performance
  2. Untick Use recommended performance settings
  3. Tick Use hardware acceleration when available, then restart

Safari has it on already. To check any Chromium browser, open chrome://gpu (or brave://gpu): WebGL should say Hardware accelerated. Work laptops sometimes lock this setting; if so, use the course pages.
