The 3D map needs graphics acceleration. To turn it on:
Chromechrome://settings/system → turn on "Use graphics acceleration when available" → Relaunch
Bravebrave://settings/system → same switch → Relaunch. Still blank? Set Shields to Standard for this site
Edgeedge://settings/system → same switch → Restart
FirefoxSettings → General → Performance → untick "recommended", tick "hardware acceleration" → restart
Then reload this page. Work laptops sometimes lock this setting; the bundle pages above work either way.
